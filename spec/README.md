# Спека Platform API

`api.yaml` — вендоренная копия OpenAPI-спеки Aplaut Platform API. Из неё `build.rs`
генерирует таблицы фильтров, include и параметров scroll, а тест `spec_drift`
проверяет, что каждой команде CLI соответствует операция спеки.
